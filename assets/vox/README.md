# Модели из MagicaVoxel

Сюда кладутся файлы `.vox` из MagicaVoxel. Claude превращает их в кирпичные модели `.glb` в `assets/bricks/`.

Правила:
- 1 кубик = 1 кирпичик с пупыркой.
- Светящиеся кубики (трещины, кристаллы, лампы) красить чисто розовым `#FF00FF`. В игре они станут неоновыми и получат цвет редкости.
- Имя файла латиницей без пробелов: `meteor_big.vox`.
- Размер: метеорит 8–12 кубиков в поперечнике, кристалл около 6×6×12, декор до 30 по любой стороне.

Как загрузить: на GitHub открыть эту папку → Add file → Upload files → перетащить файл → Commit changes.
