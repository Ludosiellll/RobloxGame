**Макет для Windows** (64-бит, Windows 10 и новее).

- `Maket-Setup.exe` — установщик: ставит программу, делает ярлык «Макет» на рабочем столе и в меню «Пуск», сразу запускает.
- `Maket-Portable.exe` — версия без установки: один файл, запускается откуда угодно.

Программа не подписана платным сертификатом, поэтому при первом запуске Windows покажет синее окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».

Проекты и свои модели хранятся на компьютере и сохраняются между запусками. Интернет для работы не нужен.

`windows-check.png` — снимок окна программы с автоматической проверки на Windows перед выпуском.
