# CLAUDE.md

HTML5-игры для каталога Яндекс Игры на TypeScript + Vite.

- Контекст проекта, правила и решения лежат в репозитории `Ludosiellll/RobloxGameNotes` (папка на ПК `D:\robloxgame`). Прочитай его `CLAUDE.md` и `AGENTS.md` до начала работы и обновляй заметки по их правилам.
- Работать только в репозиториях `Ludosiellll/RobloxGame` (этот, ветка `main`) и `Ludosiellll/RobloxGameNotes` (ветка `master`). Имена репозиториев остались от Roblox-версии.
- У пользователя только веб-версия Claude: ничего не ставит и не запускает. Он получает архив и скриншоты в чате и загружает архив в консоль Яндекс Игр.
- Проверяй сам: `npm run check`, `npm run build -- <id>`, `npm run shots -- <id>` и смотри скриншоты. Не говори «готово», пока сборка без ошибок, а скриншоты просмотрены.
- Игра общается с Яндексом только через `shared/platform` (`boot()` → `Platform`). SDK напрямую из игры не вызывать.
- Требования модерации — `docs/PUBLISH.md`, источник — https://yandex.ru/dev/games/doc/ru/concepts/requirements.md (Markdown-версии страниц доступны через curl). Перед изменением правил платформы перечитай первоисточник.
- Обязательно: `<script src="/sdk.js">` относительным путём; `markReady()` когда можно играть; пауза звука и игры при рекламе и потере фокуса; автоопределение языка (ru, en, tr); сохранение прогресса сразу после действия; реклама только в логических паузах, за награду — только по кнопке с понятной наградой.
- Запрещено: интерактивный ИИ в игре (пункт 1.23), внешние ссылки, сторонняя реклама, абсолютный адрес `games.s3.yandex.net`, пробелы и кириллица в именах файлов.
- Ключи и токены не хранить в репозитории.
