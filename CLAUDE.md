# CLAUDE.md

«Макет» — 3D-приложение для дизайна интерьера и планировки в браузере. TypeScript + Vite + three.js, без фреймворков.

- Контекст проекта, правила и решения лежат в репозитории `Ludosiellll/RobloxGameNotes`. Прочитай его `CLAUDE.md` и `AGENTS.md` до начала работы и обновляй заметки по их правилам.
- Работать только в репозиториях `Ludosiellll/RobloxGame` (этот, ветка `main`) и `Ludosiellll/RobloxGameNotes` (ветка `master`). Имя репозитория осталось от прошлого проекта.
- У пользователя только веб-версия Claude: он ничего не ставит и не запускает. Собирай и проверяй сам: `npm test`, `npm run build`, `node scripts/shots.mjs` и смотри снимки. Пользователю приложение отдаётся страницей-артефактом.
- Логика — чистые функции в `src/core` с тестами (сначала тест, потом код). Проект — неизменяемый документ (`src/core/doc.ts`), все правки через функции оттуда; 3D и интерфейс только отображают документ.
- Вид: макетный коврик, белые «пенокартонные» панели, жёлтый цвет инструмента. Шрифты Sofia Sans Condensed, Geologica, JetBrains Mono. Не добавлять градиенты, стекло, скругления больше 3px.
- Модели и другие материалы — только с лицензией, разрешающей использование (встроенный набор — Kenney, CC0).
- Ключи и токены не хранить в репозитории.
