# Публикация в Яндекс Играх

Источник требований — [полный список](https://yandex.ru/dev/games/doc/ru/concepts/requirements) и [поля черновика](https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft). Сверено 2026-11-21. Номера пунктов ниже — из полного списка.

## Аккаунт разработчика (один раз)

Источник — [Аккаунт разработчика](https://yandex.ru/dev/games/doc/ru/console/manage-account) и [Монетизация](https://yandex.ru/dev/games/doc/ru/services/about-monetization), сверено 2026-11-21.

1. Нужен Яндекс ID именно с логином Яндекса (вида `имя@yandex.ru`). С почтой gmail.com, mail.ru и другими реклама может не подключиться. На один Яндекс ID — один аккаунт разработчика.
2. Открой [регистрацию в консоли](https://games.yandex.ru/console/developer/signup).
3. Введи имя разработчика: латинские буквы, цифры, пробел, дефис, подчёркивание; без почты и ссылок. Его видят игроки. Сменить потом можно только письмом на games-partners@yandex-team.ru.
4. Прими условия (зависят от страны) и условия показа игр в ЕС, нажми «Создать профиль». Теперь можно добавлять игру и заполнять черновик.
5. Нажми «Продолжить регистрацию», укажи страну и тип. Модерация и выплаты откроются только после договора:
   - ИП или юрлицо — договор прямо в консоли (единая лицензионная схема): ИНН, ОГРН, банк, проверка несколько рабочих дней.
   - Без ИП — консоль отправит в [Рекламную сеть Яндекса](https://partner.yandex.ru/). В России там оформляются как самозанятый (форма «физлицо» только для нерезидентов России). Физлицо из Беларуси принимает договор оказания услуг.
   - Физлицо из другой страны (например, Грузии) — без регистрации: при создании профиля английское соглашение, затем в РСЯ оферта для физлиц «других стран» (Settings → Payout): адрес, имя латиницей как в банке, SWIFT, IBAN, скан паспорта. Выплаты в USD банковским переводом. Покупки включают письмом на games-partners@yandex-team.com с названием и ID игры после статуса «Offer accepted». [Справка РСЯ](https://yandex.com/support/partner/en/payments/with-other-individuals).
6. Монетизация подключается один раз: для каждой новой игры рекламные блоки создаются сами.

## Шаги

1. Войди в [консоль Яндекс Игр](https://games.yandex.ru/console) под аккаунтом разработчика (раздел выше).
2. Добавь игру. Откроется черновик.
3. Заполни черновик (поля ниже) и загрузи архив `<id>.zip` от Claude.
4. Включи «Игра использует облачные сохранения» (пункт 1.11), если игра сохраняет прогресс. Все наши игры сохраняют.
5. Отправь на модерацию. Если вернули замечания, пришли их Claude текстом или скриншотом.

## Что готовит Claude

| Поле | Требование |
| --- | --- |
| Архив | `index.html` в корне, до 100 МБ в распакованном виде, без пробелов и кириллицы в именах файлов (1.21, 1.22). Скрипт сборки проверяет сам |
| Иконка | 512 × 512, PNG, не скриншот из игры (5.6) |

| Обложка на витрину | 1560 × 520, PNG/JPG, по желанию |

| Вертикальное видео | по желанию: 9:16, те же условия |
| Скриншоты | обязательно; десктопные только альбомные; реальный геймплей не меньше 70% кадра |
| Название | одинаковое в игре и в черновике на каждом языке, уникальное в каталоге (5.1.3, 5.12) |
| Об игре, Как играть | обязательно; в «Как играть» полностью описать управление (2.2) |
| Языки | ru, en, tr — автоопределение через SDK (2.14) |

## Проверки перед отправкой

Технические (раздел 1):
- SDK подключён `<script src="/sdk.js">`, `LoadingAPI.ready()` вызывается, когда можно играть (1.19).
- Звук останавливается при потере фокуса (1.3) и во время рекламы (4.7).
- На телефоне игра управляется жестами, долгое нажатие не выделяет текст и не открывает меню (1.6.1).
- На компьютере поле растянуто до края, длинная сторона не больше двух коротких (1.6.2.1, 1.6.2.2); управление мышью или клавиатурой, не зависит от раскладки.
- Нет прокрутки страницы, ничего не обрезается при повороте и смене размера окна (1.10).
- Прогресс сохраняется сразу после действия и переживает перезагрузку (1.9).
- Есть монетизация: реклама или покупки (1.12). Покупки — только через SDK, с консумированием и ценой в валюте портала (1.13).
- Нет интерактивного ИИ (1.23), игра выглядит законченной (1.15).

Игровой опыт (раздел 2):
- Есть нарастание сложности и понятный сеттинг (2.8), основное содержание дольше 10 минут или есть мотивация переигрывать (2.9).
- Рейтинг игры должен держаться выше 30, иначе через 3 недели её снимут (2.13).

Реклама (раздел 4):
- Только через SDK (4.1), только в логических паузах (4.4).
- Реклама за награду — по кнопке, где ясно, что будет реклама и какая награда (4.5).
- Свои рекламные блоки и имитации запрещены; из дополнительных допустим только стики-баннер (4.6).

Содержание (раздел 3):
- Нет политики, религии, реалистичного насилия, гаданий с покупками (3.4).
- Все материалы наши или с правом использования (3.5); игра не копирует другую из каталога (3.6).
- Нельзя выиграть реальные деньги и призы (3.7).
