# ИИ видит игру сам: Studio MCP на твоём компьютере

У Roblox Studio есть встроенный MCP-сервер. Через него ИИ-агент на этом же компьютере может запускать Play, читать Output, управлять персонажем и делать скриншоты. Тогда агент проверяет игру сам, а тебе не нужно пересылать скриншоты.

Сервер работает только на том компьютере, где открыт Studio. Облачная сессия Claude к нему не подключится, поэтому агент должен работать на твоём ПК.

Roblox предупреждает: подключённый клиент может читать и менять открытые в Studio плейсы. Подключай только Claude.

## 1. Поставь Claude Code на ПК

Подойдёт приложение Claude для компьютера (раздел Code) или Claude Code в терминале. Установка описана на https://code.claude.com/docs.

## 2. Включи MCP-сервер в Studio

1. Обнови Roblox Studio до последней версии.
2. Открой Assistant, нажми меню `...` → Manage MCP Servers.
3. Включи Enable Studio as MCP server.
4. В списке Quick connect выбери Claude Code.
5. Перезапусти Studio и Claude Code.

Названия пунктов взяты из справки Roblox (https://create.roblox.com/docs/studio/mcp) и могут отличаться. Если какого-то пункта нет, пришли скриншот меню Assistant. Если Quick connect не видит Claude Code, на этой же странице справки есть ручная настройка (запись `Roblox_Studio` для файла настроек MCP).

## 3. Дай агенту промпт

Открой Claude Code в папке `D:\RobloxGameCode` и скопируй ему промпт ниже целиком.

```text
Ты работаешь на Windows-ПК Дениса над игрой Roblox «Meteor Rain». Код игры лежит в D:\RobloxGameCode (репозиторий Ludosiellll/RobloxGame, ветка main). Заметки проекта лежат в D:\robloxgame (репозиторий Ludosiellll/RobloxGameNotes, ветка master).

Сначала:
1. Выполни git pull в обеих папках.
2. Прочитай D:\robloxgame\CLAUDE.md, D:\robloxgame\AGENTS.md и D:\RobloxGameCode\CLAUDE.md и следуй им.
3. Проверь, что тебе доступны инструменты MCP-сервера Roblox_Studio. Если их нет, остановись и скажи об этом.

Как работать:
- Скрипты меняй только в файлах репозитория. Rojo переносит их в Studio, когда запущен start.cmd. В Studio скрипты не правь.
- Карту (Workspace) руками не меняй. Пересобирай её только командой из docs/ASSET_SETUP.md.
- Проверяй сам через Studio: запускай Play, читай Output, двигай персонажа, делай скриншоты, затем останавливай Play.
- В main отправляй только рабочие изменения. Денис забирает их через update.cmd.
- Игру публикуй (Publish) и меняй её настройки доступа только по просьбе Дениса.
- Ключи и токены не храни в репозиториях и заметках.
- После каждой задачи обновляй заметки по правилам AGENTS.md.

Первая задача: пересобери кратер командой
require(game.ServerStorage.StudioTools.CraterBuilder:Clone()).build()
Затем нажми Play и проверь три вещи:
1. Деревья и постройки стоят на земле.
2. На своей беговой дорожке персонаж бежит сам, а число скорости растёт.
3. В Output нет красных ошибок.
Сделай скриншоты. Что сломано, исправь в коде и проверь ещё раз. В конце дай Денису короткий отчёт на русском.
```
