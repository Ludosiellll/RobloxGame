# Этап 1: чек-лист проверки в Studio

Перед проверкой: `update.cmd` → `start.cmd` → Rojo Connect, затем всё из [ASSET_SETUP.md](ASSET_SETUP.md). Кратер нужно пересобрать (`CraterBuilder.build()`): 2026-11-06 дамбы к ядру перенесены на 67.5° и 247.5°.

Отмечай пункты и присылай Claude текст из Output, если что-то не так.

## Запуск (задачи 6–8)
- [ ] Play → в Output есть `[Tests] … passed, 0 failed`.
- [ ] `[Assets] OK` по всем пунктам или понятный список `MISSING` с подсказкой, куда положить.
- [ ] Одна жёлтая строка про режим памяти (в Studio без API это нормально), красных ошибок нет.
- [ ] Кнопка DEBUG слева. `list` показывает команды, `money 1000` даёт деньги.

## Кратер и ворота (задача 9)
- [ ] Кратер собран: 4 яруса, ров с лавой, ядро, 2 дамбы, спуски между ярусами.
- [ ] `zone` пишет, в какой зоне стоишь.
- [ ] С 0 перерождений видны стены «REBIRTH N REQUIRED» на входах в закрытые секторы.
- [ ] Спрыгнул в закрытую зону — вернуло назад и пришло уведомление.
- [ ] `rebirths 5` — часть стен пропала, `tp 6` пускает.
- [ ] Встал на гейзер у подножия обрыва — подбросило на ярус выше.

## Существа (задача 10)
- [ ] `zoo` — за базой 1 рядами 63 существа со своими текстурами.
- [ ] Все шевелятся (Idle). В Output нет строк `[Anim] … gentle bob instead`; если есть — пришли список.
- [ ] `zoo Golden`, `zoo Diamond`, `zoo Lava`, `zoo Galaxy`, `zoo Rainbow` — мутации видно по материалу, у Lava огонь, у Rainbow бегут цвета. `zoo clear` убирает.

## Базы и доход (задача 11)

- [ ] `give Epic` — существо на площадке, над ним имя, редкость, «$X/s». Деньги растут каждую секунду, в списке игроков есть Cash.

- [ ] Нетронутый камень исчезает через 90 секунд.
- [ ] `meteor Secret` — объявление на весь сервер.
