# Этап 3: чек-лист проверки в Studio

Сначала `update.cmd`, Rojo Connect и шаг **3а** из [ASSET_SETUP.md](ASSET_SETUP.md): пак питомцев в `ReplicatedStorage.Packs.Pets`, дорожки в `ReplicatedStorage.Packs.TreadmillProgression`.

## Яйца и вылупление
- [ ] На рельсе слева есть Eggs и Pets.
- [ ] Eggs: 11 яиц, цены в долларах игры ($1K … $10B), у закрытых — «REBIRTH N».
- [ ] `money 5000` → Colorful Egg: яйцо трясётся по центру экрана, вспышка цвета редкости, питомец, редкость и бонус («+5% Speed»).
- [ ] Без денег — «Not enough money», закрытое яйцо — «Rebirth more to open this egg».
- [ ] `egg Emperor` (отладка) — вылупляется редкий питомец.

## Питомцы
- [ ] Первый вылупленный питомец сразу идёт за тобой: позади, подпрыгивает, когда бежишь.
- [ ] Pets: рюкзак, у взятых метка E, кнопка UNEQUIP убирает, EQUIP берёт. Четвёртого взять нельзя («You can take 3 pets»).
- [ ] `pets` — бонусы скорости, удачи и дохода совпадают с взятыми питомцами. Питомец на скорость — бежишь быстрее, на доход — «+$X/s» вырос.
- [ ] Второй игрок видит твоих питомцев.
- [ ] Перерождение — питомцы остались.
- [ ] Без пака питомцев — цветные шарики с именами и одна жёлтая строка `[Pets]` в Output.

## Беговые дорожки
- [ ] Слева от базы дорожка уровня 1 с подписью «Tier 1 · +0.2 speed/s».
- [ ] Встал на ленту и бежишь — остаёшься на месте, лента едет, скорость растёт примерно на 0.2 в секунду (`econ` или скорость бега).
- [ ] Стоишь на ленте без движения — скорость не растёт. С метеоритом в руках — не растёт.
- [ ] `rebirths 5` — у базы дорожки 6, 5, 4.
- [ ] Без пака дорожек — простые полосы и одна жёлтая строка `[Treadmill]`.

## Итог
- [ ] 10 минут игры: вылупить, взять питомцев, побегать на дорожке, переродиться — в Output нет красных ошибок.
