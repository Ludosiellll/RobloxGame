# Первая настройка компьютера

Нужно один раз поставить Git, Rokit и Rojo, скачать этот репозиторий и установить плагин Rojo в Studio.

Это может сделать ИИ-агент с доступом к компьютеру. Скопируй ему промпт ниже целиком.

## Промпт для агента

```text
Ты настраиваешь на этом Windows-компьютере окружение для разработки игры в Roblox. Код игры пишет другой ИИ в репозитории GitHub, а программа Rojo переносит его в Roblox Studio. Твоя задача — только установить и проверить инструменты. Код не пиши и не меняй.

Ограничения:
- Не трогай папку D:\robloxgame. Это отдельное рабочее пространство с заметками.
- Ничего не коммить и не пушь в GitHub. Не меняй файлы внутри скачанного репозитория.
- Не вводи логины, пароли и токены сам. Если нужно войти в GitHub, попроси пользователя войти в открывшемся окне браузера.
- Ставь только то, что перечислено ниже. Если шаг не получился, остановись и покажи полный текст ошибки. Не придумывай обходные пути.
- Перед установкой проверь, не стоит ли программа уже. Если стоит, пропусти установку.
- После установки каждой программы открывай новое окно терминала, чтобы обновился PATH.

Шаги:
1. Git. Проверь: git --version. Если его нет: winget install --id Git.Git -e --source winget
2. Rokit (менеджер инструментов Roblox). Проверь: rokit --version. Если его нет: winget install --id Rojo.Rokit -e
   Если winget не нашёл пакет, используй официальный установщик в PowerShell:
   Invoke-RestMethod https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.ps1 | Invoke-Expression
3. Скачай репозиторий: git clone https://github.com/Ludosiellll/RobloxGame.git D:\RobloxGameCode
   Если диска D: нет, клонируй в %USERPROFILE%\RobloxGameCode.
   Если папка уже существует и в ней этот репозиторий, просто выполни в ней git pull.
4. Перейди в папку репозитория и выполни: rokit install
   Он поставит Rojo той версии, что указана в файле rokit.toml. Если Rokit спросит, доверять ли инструменту rojo-rbx/rojo, ответь да. Другим инструментам не доверяй.
5. В папке репозитория проверь: rojo --version. Версия должна совпадать с rokit.toml.
6. Поставь плагин Rojo в Studio: rojo plugin install
   Проверь, что появился файл %LOCALAPPDATA%\Roblox\Plugins\RojoManagedPlugin.rbxm
7. Проверь, что проект собирается: rojo build default.project.json -o build\check.rbxlx
   Если сборка прошла, удали папку build.

В конце дай отчёт: по каждому шагу — выполнен, пропущен (уже было) или ошибка с полным текстом. Укажи путь к папке репозитория и версии git, rokit и rojo.

Затем скажи пользователю:
1. Закрыть Roblox Studio, если он открыт, и открыть заново.
2. Запустить start.cmd в папке репозитория и не закрывать это окно.
3. В Studio открыть плейс (можно новый Baseplate), на вкладке Plugins нажать Rojo, затем Connect. Если Rojo покажет список изменений, нажать Accept.
4. Нажать Play и открыть окно Output (View → Output). Там должны появиться строки "[Server] Rojo работает" и "[Client] Rojo работает".
```

## Проверка

Если в окне Output появились обе строки (`[Server] Rojo работает` и `[Client] Rojo работает`), значит всё настроено. Если нет, отправь Claude текст ошибки или скриншот.
