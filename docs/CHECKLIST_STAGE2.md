# Этап 2: чек-лист проверки в Studio

Сначала `update.cmd` и Rojo Connect. Этап 1 должен работать ([CHECKLIST_STAGE1.md](CHECKLIST_STAGE1.md)). Отладочные команды — в кнопке DEBUG.

## Окна (рельса слева)
- [ ] Слева 4 квадрата: Shop, Index, Rebirth, Settings. Каждый открывает своё окно, повторное нажатие или X закрывает.
- [ ] На телефоне (Test → Device → любой телефон) окна помещаются на экран.

## Магазин улучшений
- [ ] `money 100000` → Shop: строки Strength и Base Slots с ценой ($150 и $500 на старте), кнопка BUY.
- [ ] Покупка Strength — уведомление «Strength 1!», цена выросла, с метеоритом бежишь быстрее.
- [ ] Покупка Base Slots — на базе открылась новая площадка.
- [ ] Без денег — «Not enough money», деньги не ушли в минус. Быстрые многократные нажатия списывают ровно за каждую покупку.

## Продажа
- [ ] У своего существа подсказка «Sell $X» (держать), продаёт и даёт деньги. У чужой базы подсказок нет.
- [ ] Зелёная площадка в переднем правом углу базы → окно Sell: «Sell below Rare/Epic/…» с количеством и суммой, кнопка SELL продаёт только слабее выбранной редкости.

## Перерождение
- [ ] `econ` показывает цены и порог перерождения.
- [ ] Окно Rebirth: «Rebirth 0 → Rebirth 1», «x1 Money → x1.5 Money», полоска денег до $25K.
- [ ] С $25K и больше — Rebirth: база пустая, 6 мест, сила 0, деньги 0, доход ×1.5, ворота зоны 5 исчезли, на весь сервер объявление.
- [ ] Перерождение с метеоритом в руках — метеорит остался в руках, доставка кладёт существо на пустую базу.
- [ ] Debug `rebirth` перерождает без накопления денег (для быстрых проверок).

## Индекс
- [ ] Окно Index: секции по редкостям, пойманные существа открыты, остальные «???».
- [ ] Новое существо после доставки сразу открывается в индексе.
- [ ] Собрал все Common (или дай их через `give`) → CLAIM даёт награду один раз.

## Настройки
- [ ] Ползунок Sound меняет громкость взрывов. Camera Shake выключает тряску. Low Detail — воронки без камней.
- [ ] Перезашёл в опубликованном плейсе — настройки сохранились.

## Лидерборды
- [ ] За каждой базой 3 доски: MOST CAUGHT, BEST CATCH $/s, TOTAL EARNED. Через 2 минуты там ты.
- [ ] В опубликованном плейсе значения видны и с другого сервера. Если DataStore недоступен — одна жёлтая строка `[Leaderboard]` раз в 2 минуты, доски не пустеют.
